نسخهٔ ۵۹ درگاه موزیکال
این بسته از کد اصلی همان نسخه استخراج شده و شامل کد برنامه، داده‌های CSV، ارتباطات، راهنما و تاریخچه است.
داده‌ها در پوشهٔ source/public قرار دارند. نام قدیمی musical_portal_4409.csv به معنی تعداد فعلی فیلم‌ها نیست.
برای حفظ حجم مناسب، فقط فایل‌های ZIP پشتیبان نسخه‌های قدیمی از بسته حذف شده‌اند؛ سایر فایل‌های ثبت‌شدهٔ نسخهٔ ۵۹ بدون تغییر موجودند.
این بسته شامل خروجی آمادهٔ استقرار نیست؛ برای اجرای برنامه، README و package.json در پوشهٔ source را ببینید.
نسخه و شمار ردیف‌های جداول در BACKUP_MANIFEST.json ثبت شده‌اند.
